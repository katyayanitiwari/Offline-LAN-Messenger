# Offline LAN Messenger

## Project Overview

Offline LAN Messenger is a browser-based communication application developed using C++ and Web technologies. It allows users connected to the same Local Area Network (LAN) to communicate without requiring an internet connection.

The project is designed for secure communication within an authorized local network.

---

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Winsock (Networking)

---

## Features

- User Login
- Real-Time Chat
- Online Users
- Private Messaging
- Group Chat
- Broadcast Messaging
- File Sharing
- Chat History
- Message Encryption
